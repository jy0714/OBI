----------------------------------------------------------------
변경 위치: 파일 상단 import 및 파일 하단 (기존 mock 코드는 그대로 유지)

[import 추가]
  - import json
  - import requests

[추가된 상수]
  PROVIDER_DEFAULTS
    - 3개 프로바이더의 기본 모델명·URL 정의
      · ollama    : qwen2.5:7b  /  http://localhost:11434
      · openai    : gpt-4o-mini /  https://api.openai.com/v1
      · anthropic : claude-haiku-4-5-20251001  /  https://api.anthropic.com

  _SYS
    - 모든 프로바이더에 공통으로 사용하는 시스템 프롬프트 문자열

[추가된 함수]

  build_llm_prompt(info, crit_df, cands, tl)
    - 분석 데이터(인적 사항, SA팀 기준 점검 결과, 위험 후보 사건,
      확인 필요 이벤트 최대 30건)를 하나의 프롬프트 문자열로 변환
    - 모든 프로바이더에서 공통 사용

  _make_messages(info, crit_df, cands, tl)
    - system + user 역할의 messages 배열 생성 (내부 헬퍼)

  stream_analyze(cfg, info, crit_df, cands, tl)
    - cfg["provider"] 값에 따라 아래 3개 함수 중 하나로 라우팅하는
      공개 진입점 (제너레이터)
    - cfg 구조: {"provider": str, "model": str, "base_url": str, "api_key": str}

  _stream_ollama(cfg, ...)
    - POST {base_url}/api/chat  (스트리밍)
    - 응답 파싱: message.content 필드 yield
    - 404 → 모델 없음 안내 메시지 (ollama pull 명령 포함)
    - ConnectionError → 서버 미실행 안내

  _stream_openai(cfg, ...)
    - POST {base_url}/chat/completions  (SSE 스트리밍)
    - OpenAI 뿐 아니라 Groq·Together AI 등 호환 엔드포인트에서도 동작
    - 응답 파싱: SSE "data: {...}" 라인에서 choices[0].delta.content 추출
    - "data: [DONE]" 수신 시 종료
    - 401 → API 키 오류 / 404 → 모델·엔드포인트 없음 안내

  _stream_anthropic(cfg, ...)
    - POST {base_url}/v1/messages  (SSE 스트리밍)
    - messages 배열에서 system 역할을 분리해 Anthropic 형식에 맞게 전송
    - max_tokens: 4096 고정
    - 응답 파싱: type=content_block_delta 이벤트에서 delta.text 추출
    - type=message_stop 수신 시 종료
    - 401 → API 키 오류 / 404 → 모델 없음 안내

4. obi_preprocess.py  [기존 파일 수정 - 버그 수정]
----------------------------------------------------------------
변경 위치: LogWorkbook._read_via_excel() 메서드

문제:
  암호화된 Excel 파일 처리 시 win32.DispatchEx("Excel.Application") 호출에서
  Excel이 미설치된 경우 COM 에러(-2147221005, CO_E_CLASSSTRING)가
  raw 예외로 그대로 노출되어 사용자가 원인을 알 수 없었음

변경 내용:
  DispatchEx() 호출을 try/except로 감싸고,
  실패 시 SystemExit으로 아래 안내 메시지를 표시하도록 수정:
    - 파일이 암호화(DRM·민감도 레이블)되어 있음을 알림
    - Excel 설치가 필요함을 설명
    - COM 에러 코드 표시 (디버깅용)
    - 해결 방법 2가지 안내:
        ① Excel이 설치된 PC에서 앱 실행
        ② 파일을 일반 xlsx로 변환 후 재업로드

  CoUninitialize()를 예외 발생 전에 먼저 호출하도록 처리
  (COM 초기화 상태 정리)
